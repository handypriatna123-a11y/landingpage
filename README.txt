HANDYFLY — LANDING PAGE DEMO

CARA MENJALANKAN DI VS CODE
1. Ekstrak file ZIP ini.
2. Buka VS Code > File > Open Folder.
3. Pilih folder handyfly_landing_page.
4. Buka file index.html.
5. Jalankan dengan ekstensi Live Server (klik kanan index.html > Open with Live Server), atau buka index.html langsung di browser.

FITUR
- Login dan daftar akun demo.
- Pemesanan pesawat, kereta, bus, dan hotel.
- Pilihan kelas Basic, Medium, Elite, VIP.
- Promo contoh: HEMAT15, JALAN25, INAP10.
- Pilihan pembayaran QRIS atau e-wallet/transfer bank.
- Contoh struk setelah simulasi pembayaran.
- Rekomendasi destinasi/penginapan.

CATATAN PENTING
Ini adalah proyek front-end untuk latihan. Login disimpan di browser dan tidak aman untuk produksi.
Harga, QRIS, nomor tujuan, dan status pembayaran adalah simulasi. QR yang ditampilkan bukan QRIS asli dan tombol pembayaran tidak memindahkan uang. Agar dapat menerima pembayaran sungguhan, perlu backend, database, autentikasi yang aman, serta integrasi penyedia pembayaran resmi (payment gateway) dan verifikasi transaksi di server.
